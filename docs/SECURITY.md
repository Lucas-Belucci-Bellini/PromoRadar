# Segurança

- Segredos nunca entram no Git.
- Dados externos são não confiáveis até validação.
- Tokens de parceiros ficam em variáveis de ambiente.
- Endpoints administrativos terão autenticação e autorização.
- Logs não devem registrar segredos.
- HTTPS será obrigatório no ambiente público.
- Jobs e integrações externas devem ter limites, timeouts e tratamento de falhas.
